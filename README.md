# Hopper

A small, pixel-styled Minecraft mod manager that latches onto the Minecraft folder you already have.
No instances, no accounts, no launcher: it manages `mods/`, `resourcepacks/` and `shaderpacks/`.

## Download

Grab the latest build from [Releases](https://github.com/p1e2r/hopper/releases/latest):

| Platform | File |
| --- | --- |
| macOS, Apple Silicon | `Hopper-macos-apple-silicon.dmg` |
| macOS, Intel | `Hopper-macos-intel.dmg` |
| Windows | `Hopper-windows-x64.exe` |
| Linux | `Hopper-linux-x64.tar.gz` |

The macOS app isn't notarized: the first time, right-click it and choose **Open**.

## Features

- **Finds your folder** automatically (`~/Library/Application Support/minecraft`, `%APPDATA%\.minecraft`, `~/.minecraft`); change it under **Options**
- **Pick the version and loader you play** in the top bar (Fabric, Quilt, Forge, NeoForge). Versions found in `versions/` are listed first, then every Minecraft release. Everything from Modrinth, dependencies included, is downloaded for that version and loader
- **Recognises what you already have**: each file's SHA-1 is looked up on Modrinth, and matches are shown with their Modrinth name, version and a link to the project page. Files that aren't on Modrinth keep their own name. Can be turned off under **Options**
- **Modrinth built in**: search and one-click install mods, resource packs and shaders
- **Manual files**: the `+ .jar` / `+ .zip` buttons, or drop files on the window; zips are sorted into resource packs or shaders automatically
- **Switches**: turn anything off without deleting it (renames to `name.jar.disabled`, the same convention other launchers use)
- **Remove** sends files to the trash

## Build

```sh
cargo run --release
```

Built with [GPUI](https://gpui.rs). On Linux you need Vulkan plus the dev packages listed in `.github/workflows/release.yml`.

## Releases

Every push to `main` builds all platforms and publishes a GitHub Release, tagged with the
version in `Cargo.toml` (`v0.3.0`). If that version was already released, the build is
published as `v0.3.0-build.N`, so bump the version in `Cargo.toml` for a clean tag.
Pushes to `dev` and pull requests only build and test.
