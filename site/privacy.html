Privacy policy

Applies to the Hopper desktop app and this website. Last updated 15 November 2026.

Short version: Hopper has no accounts, no analytics and no telemetry. The developer never receives any data from the app. The only service it talks to is Modrinth, to search for and download the things you ask for.

What the app sends, and where

Hopper only connects to Modrinth (api.modrinth.com and cdn.modrinth.com), in these cases:

  • When it starts: it downloads the list of Minecraft versions for the version picker.
  • When you search or browse: it sends your search text, the type of content (mods, resource packs or shaders) and the Minecraft version and loader you picked.
  • When you install something: it requests that project's files, and those of any required dependencies, and downloads them.
  • Recognising your files (on by default, can be turned off in Options): it sends the SHA-1 hash of each mod, resource pack and shader file in your Minecraft folder so Modrinth can say which project each one belongs to. A hash is a fingerprint of a file; it does not contain the file's contents. File names, folder paths and the files themselves are never sent.

Every request identifies itself as hopper-mod-manager/<version>, which Modrinth asks all apps to do. Like any website, Modrinth also sees your IP address. Their handling of that data is covered by Modrinth's privacy policy.

What stays on your computer

  • Your settings: the Minecraft folder you chose, the version and loader you picked, and your Options switches. They are saved in hopper/config.json in your system's settings folder and never leave your computer.
  • Everything Hopper does to files (installing, switching on or off, moving to the trash) happens in your Minecraft folder only.

Links

Project pages, the GitHub link and similar buttons open in your web browser. What happens there is covered by that site's own policy.

This website

This site is hosted on GitHub Pages and loads the latest version number from GitHub's API. It uses no cookies, analytics or trackers of its own. GitHub may log visits, as described in GitHub's privacy statement. Downloads are served from GitHub Releases.

Changes and contact

Changes to this policy are made in the public source code, so every change is visible in its history. Questions can be asked by opening an issue on GitHub.
